# Sunny Hop Adventure

A cheerful pixel-art campus platformer. Run, jump, collect coins, and reach the finish flag.

## Play
Download index.html and open it in a modern desktop browser, or use GitHub Pages once enabled. No Higgsfield account, sign-in, API key, or internet connection is required after downloading.

## Controls
A/D or Left/Right: move. Space/W/Up: jump. Escape: pause. Mobile: on-screen controls. SOUND toggles mute; independent music and effects volume sliders are on the menu.

The game includes the approved campus artwork, round gold coins, corrected sparkle effect, distinct menu/level music, victory jingle, and descending fall cue. Unlimited checkpoint retries. Progress and settings stay in your browser when storage is available. No analytics or cloud account.

## Hosting
The publishing workflow imports a checksum-verified standalone artifact and publishes through GitHub Pages. If site setup requires owner approval, open Settings → Pages, select GitHub Actions as source, then rerun Publish Sunny Hop.
